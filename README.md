# MIS Career Hub — Official Version

مشروع منصة حقيقية مبني باستخدام Next.js + Supabase.

## المميزات
- موقع عام للطلاب
- تسجيل دخول بالبريد وكلمة المرور
- قاعدة بيانات حقيقية
- لوحة تحكم للإدارة
- إضافة وحذف الكورسات
- قابل للنشر على الإنترنت

## التشغيل
1. ثبت Node.js.
2. افتح Terminal داخل المشروع.
3. نفذ:
   npm install
   npm run dev
4. أنشئ مشروع Supabase وضع القيم في ملف `.env.local` بناءً على `.env.example`.
5. نفذ ملف `supabase.sql` داخل SQL Editor في Supabase.

## النشر
يمكن نشر المشروع على Vercel وربطه بدومين خاص.
